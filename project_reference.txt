Setting up SSH connection between two Ubuntu containers in Docker

Why learn this?

- Improved Security.
- Easy of Management.
- Better colaboration.
- Scalability.
- Portability

Steps

1° Run Container 1 and install openssh-server.

2° Run Container 2 and install openssh-client.

3° Set new password for root user in Container 1.

Commands

- `Docker pull ubuntu`
- `docker images`

!image.png

### **CREATION OF CONTAINER 1**

- `mkdir project1` → ls → `cd /project1`

!image.png

- Inside project1, run `docker run -it --name container1 ubuntu`

!image.png

- Since it’s in interact mode, we can install openssh-server

!image.png

- run `apt-get update`
- run `apt-get install openssh-server`
- run `apt-get install nano`
- run `nano /etc/ssh/sshd_config`

!image.png

- In PermitRootLogin, delete prohibited-password and change it to yes

Before:

!image.png

After:

!image.png

- Press `ctrl+s` to save it and `ctrl+x` to close it.
- run `service ssh start`
- run `exit` to leave container 1.

!image.png

### **CREATION OF CONTAINER 2**

- run `docker run -it —-name container2 ubuntu`
- run `apt-get update`
- run `apt-get install openssh-client -y`

!image.png

- exit
